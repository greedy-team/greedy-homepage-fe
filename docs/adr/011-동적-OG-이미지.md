# ADR 011. 동적 OG 이미지

- 상태: 확정 (2026-08)
- 결정자: 4기 홈페이지 TF

## 맥락

링크 공유 카드(OG)가 전 페이지 공통 1장이면, 멤버나 프로젝트를 공유해도 무엇을 공유했는지 카드에 드러나지 않아요. 반대로 페이지마다 카드를 따로 그리면 카드끼리 흩어져요. 페이지가 늘어나도 따라갈 수 있는 하나의 틀이 필요해요.

## 결정

**카드는 공통 골격 하나에 슬롯 값만 바꿔요** — 왼쪽 위 워드마크, 라벨·제목·설명·사진 슬롯.

| 어디 | 형 | 슬롯 |
| --- | --- | --- |
| 홈·전역 폴백 | 기본형 (정적 `public/og.png`) | 워드마크 중앙 + 슬로건 |
| 목록 페이지 4곳 | 페이지형 | 제목 + 페이지 부제 |
| 멤버 상세 | 멤버형 | 라벨 · 이름 · 역할 + 깃허브 사진 |
| 프로젝트 상세 | 프로젝트형 | 라벨 · 프로젝트명 · 한 줄 소개 |
| OG를 설계하지 않은 새 페이지 | 기본 동적형 | 제목만 (`ogImage({ title })` 한 줄) |

- 장식을 두지 않아요. 카드가 늘어나도 규칙이 깨질 여지를 줄여요.
- 생성기(ImageResponse/Satori)는 flex와 단색만 그려요. 시안을 이 제약 안에서 확정해 시안과 구현이 어긋나지 않아요.
- 라우트가 전부 정적 생성이라 OG도 빌드 때 PNG로 나와요. 런타임 비용이 없어요 ([ADR 002](002-데이터는-빌드타임-ISR.md)).
- 시안은 Figma "OG 이미지" 섹션에, 미리보기는 스토리북 "공유 카드"에 있어요.

## 코드 배치

- 템플릿(`OgCard`)과 생성기(`ogImage`)는 `src/app/_og`에 둬요. 화면 UI가 아니라 라우트 전용 도구라 `shared/ui`에 넣지 않아요.
- 각 라우트의 `opengraph-image.tsx`는 entity 값을 슬롯으로 옮기는 몇 줄짜리 매핑만 해요. 서버 명세가 바뀌면 이 매핑만 고쳐요.
- 카드 색은 이미지 생성기라 CSS 토큰이 닿지 않아, `tokens.css`와 같은 값을 상수로 복사해요.
- 폰트는 `pretendard` 패키지의 OTF를 빌드 때 읽어요. 별도 폰트 파일을 레포에 두지 않아요.
