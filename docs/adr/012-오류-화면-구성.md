# ADR 012. 오류 화면(404) 구성

- 상태: 확정 (2026-08)
- 결정자: 4기 홈페이지 TF

## 맥락

기본 404는 사이트 톤이 없어요. 없는 주소로 온 사람에게 필요한 건 두 가지뿐이에요 — 무슨 일이 났는지, 어디로 가면 되는지.

## 결정

- **404 숫자 대신 문구로 말해요.** 상태 코드는 사용자에게 정보가 없어요. "앗, 찾는 페이지가 없어요" 한 줄과 설명 한 문장으로 말해요.
- **행동은 홈 버튼 하나예요.** 선택지가 많으면 더 헤매요. 다른 페이지로 가는 길은 GNB가 이미 제공해서 본문에 두면 중복이에요.
- **공통 레이아웃(GNB·푸터) 안에 둬요.** 별도 레이아웃으로 고립시키면 사이트로 돌아갈 익숙한 수단까지 사라져요.
- 요소는 제목·설명·버튼 셋뿐이에요. 장식은 두지 않아요.

## 코드 배치

- 404가 뜨는 경로가 둘이라 파일도 둘이에요. 라우트 안에서 `notFound()`를 부르는 경우(없는 활동 id 등)는 `not-found.tsx`가, 어떤 라우트와도 안 맞는 주소는 `global-not-found.tsx`가 맡아요(`next.config`의 `experimental.globalNotFound`). 후자는 레이아웃을 거치지 않아서 스타일·GNB·푸터를 직접 그려요.
- 본문은 `_sections/NotFoundView.tsx` 하나를 둘이 같이 써요. 두 경로에서 화면이 갈라지지 않게요.
- 문구는 `src/app/_sections/content.ts`의 `NOT_FOUND` 상수에 둬요 ([ADR 003](003-콘텐츠-코드-분리.md)).
- 기존 디자인 시스템(Button, 타이포 토큰)만 써요. 시안은 Figma "오류 화면" 섹션에 있어요.
